## Skill 做什么

以引导式流程生成或修订生物医药、AI 制药、AI4S 与深科技研报：先确定类型、用途和范围，经有限资料侦察确认论证大纲，再开展证据研究、分析、写作与交付。支持行业全景、公司尽调、技术调研、企业战略及对外交付。

研究要求区分原始事实、公司披露、分析假设与作者判断，对齐财务和临床口径；按需要提供市场测算、情景与敏感性、逐期现金压力、估值条件和尽调工具。交付检查覆盖来源定位、计算复算、论证可读性、连续引用、中文提取和逐页版式。结构检查及算术通过不等于事实已获独立验证。

### 安装与使用

```sh
git clone https://github.com/chsmiss/guide-research-report-skill.git
mkdir -p ~/.codex/skills
cp -R guide-research-report-skill/skills/guided-research-report ~/.codex/skills/
```

已有同名 skill 时，请先备份本地版本再替换。重启或重新打开支持技能的会话后，可使用：

> 用 guided-research-report 生成一份 AI 制药行业研报，主要用于投资尽调。先引导我确定研究范围和大纲，最终交付 Word、PDF 与可复算研究包。

更多入口见 [skill README](skills/guided-research-report/README.md)。当前发布副本清理了历史测试来源中的个人绝对路径；未改变研究方法与评分逻辑。仓库中的 skill 包含方法、模板、脚本与测试，实际生成仍需要可用的研究来源和文档工具。

### 判断依据与适用范围

以下优缺点和核查结论均为所给评估文档的归纳；报告内容之外的生成过程及因果解释不由排名证明。

| 报告 | 主要优势 | 主要缺口与使用条件 |
|---|---|---|
| **codex-skill** | 评估认为来源定位与定量纪律最强：24 条连续来源、91 个 PDF 深链接，市场模型有客户 ACV 锚点，交易前端款表述精确，包含财务桥、情景、现金与估值条件 | 缺 IsoDDE/PoseBusters 技术基准、剂泰和行业资本时间序列；32 页行文较密，评估建议压缩约 15–20%。可作尽调底稿草稿，仍需按投资对象补证 |
| **玻尔写作网页** | 商业模式、估值锚、观察窗口和尽调工具突出；原文给予分析深度、决策工具满分 | 市场参考值约 150 亿美元与情景 300–450 亿美元存在矛盾，Exelixis 前端占比 8.2% 与表内复算 8.9% 不一致；需统一分母、更新财务、补逐行来源 |

## 怎样理解这次比较

五份样本的提示词、模型、信息时间、工具和资源投入未受统一控制；没有重复生成实验和盲评。排名反映所给评估者对这些具体文件的判断，不能证明 skill 造成了分数提升，也不能推导平台或模型的总体优劣。新报告的优势与仍需补齐的内容应一起阅读。

当前仓库已移除旧的 `research-report-evaluator` skill，保留四份历史报告及其证据、评分和 Git 历史。旧存档采用单维 0–5、加权 100 分制，且价格为另一种采购口径；它们仅供追溯，**不参与上面的新排名**。历史复核脚本已解除对删除 skill 的依赖，仅核对保存文件与算术。
