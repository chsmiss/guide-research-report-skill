# 引导生成研报skill

基于 `deep-tech-research-report` 2.6.0 的独立技能。以具体的正确行动引导研究和写作：说明要回答什么、怎样取得证据、怎样形成判断、怎样检查结果。采用用户的语言交流，通常使用中文。保留原版的行业地图、概率情景、现金压力、临床漏斗、尽调工具与证据纪律。

## 1. 与用户选定研报类型和用途

启动时读取 [类型与确认流程](references/report-intake.md)。先整理请求里已有的信息，再用一张简短选择卡呈现：

- **研报类型**：行业全景／公司研究与尽调／技术或学术调研／企业战略与采购／专题深度；提供与本题相关的推荐和可选项。
- **主要用途**：行业入门 `orientation`、投资尽调 `investment`、技术调研 `technical`、战略决策 `strategy`、对外交付 `publication`。用途中性时可选 `balanced`。类型决定覆盖范围，用途决定分析重点；对外交付还可作为副用途。
- **读者和任务**：知识起点、希望支持的选择、地区和对象、观察期和信息截止日、深度与交付格式。

请用户选择或确认推荐组合，再进入完整研究。用户已经明确指定类型或授权自主选择时，记录并沿用该选择。用户明确授权自主选型、拟纲并直接完成时，公开记录采用的范围与确认方式并继续。轻量修改沿用已确认的范围，只澄清影响交付的变化。

用简短范围约定列出：标题承诺、核心问题、必要比较、可获得的证据、拟交付成果和重要缺口。多用途以一个主用途为锚，副用途另列。按需使用 [计划模板](templates/report_plan.md)。

## 2. 用初步证据形成大纲，请用户确认

完成与选题直接相关的有限资料侦察，了解可获得的原始材料、关键争议和数据缺口。先形成问题与证据导向的大纲，章节标题表达待回答的问题或有依据的暂定判断。

向用户呈现：**拟定标题、核心问题、暂定主线、章节及各节任务、关键比较与图表、证据缺口、预计交付物**。说明报告相较常见公开资料将增加的核验、比较、机制解释或决策帮助。请用户确认大纲后进入完整研究和正文写作。已有获批大纲，或用户明确授权自主拟纲并直接完成时，记录该依据后执行。

等待必要的类型选择或大纲确认时，可继续整理已有资料和确认可访问性；把依赖用户选择的完整研究和正文留到确认后。后续证据推动结论和局部顺序更新时记录修改；涉及对象、主要用途或覆盖承诺的实质变化时，呈现修订大纲取得确认。

## 3. 按承诺研究能改变判断的命题

实质性研究读取 [研究执行](references/research-orchestration.md) 与 [证据核查](references/evidence-audit.md)。维护问题、证据、替代解释、缺口、下一步和预算的简短工作状态，根据新增证据调整搜索与分析。

- 用 Tier1/Tier2/Tier3 标记决策优先级。把最多精力分配给最可能改变判断、且有机会补充证据的问题。
- 对关键命题取得可行的原始记录，保留准确定位、时间、单位、分母、支持范围和来源链；以不同观察路径判断独立性。同一试验的注册、论文和新闻归入同一疗效证据链。
- 用事实、来源披露、分析假设、计算结果和作者判断明确各内容的逻辑身份。以真实取得的材料、实际执行的检查和可复算的输入填写记录。缺口附具体补证方式与影响。
- 比较时对齐期间、币种、分部、确认口径、群体、终点、随访和分母。保留进行中项目的右删失状态，分别展示口径尚待统一的预测。
- 解释 AI 改变的具体任务。因果判断写明干预、对照、资源投入和研究设计；分别处理观察、相关、机制假说和因果推断。
- 关键判断连接证据、最强替代解释、置信度、行动含义和可观察更新条件；预测同时给出期限。按需使用 judgments/challenges 底稿或等价笔记。

通用行业研报交付完整地图：需求、工作流、产业链、付费市场、技术和临床成熟度、竞争、商业模式、政策、资本周期、风险展望与尽调行动。专题围绕已确认问题配置深度。公开数据稀疏时，用有依据的区间、透明条件估计、阈值分析或明确列出的待补项承接覆盖承诺。

实质性行业或决策展望给出有日期、期限、互斥穷尽状态、数值概率、联动驱动、同口径结果、敏感性和更新条件的情景。采用经验、模型或明确标注且有理由的作者主观权重；把主观权重的依据及权重变化对决策的影响写清。描述性历史报告按约定聚焦已发生事实。

## 4. 把发现写成读者能理解的论证

起草前读取 [编辑与交付](references/editorial-design.md)，按 [用途质量映射](references/generation-quality.md) 检查已确认大纲的完成情况。

用普通语言先给出核心回答和必要语境，再组织关键比较、机制、反例、判断和行动。陌生行业可沿 **经济问题与工作流 → 技术改变的任务 → 验证与适用条件 → 价值捕获 → 决策与更新** 推进。根据研究结果调整主线，并保留大纲确认的覆盖承诺。

每节承担一个新的解释任务，先写已有证据支持的具体回答，再解释关键比较及其含义；关键限制紧接它实际影响的判断。结尾收束本轮发现与优先行动，通用研究原则集中说明。报告附录承载口径、公式、假设与来源，研究包承载命令、文件结构及执行日志。内部 `build_decision_brief.py` 输出用于选择和核对材料，读者摘要由作者重新组织。

精简文字时保留关键定量分析：付费市场范围、概率展望、适用公司的逐期现金压力，以及广泛 AI 制药报告的有来源历史临床转化漏斗。历史漏斗的身份是参照群体；AI 相关队列单独定义和展示。

## 5. 按用途验收与交付

对照已确认的类型、用途和范围，逐项检查十维质量目标：定位、完整性、证据与时效、信息增量、分析推理、定量纪律、行业落地、反证与边界、决策工具、可读性与交付。以正文位置和实际检查支撑完成情况；详见 [用途质量映射](references/generation-quality.md)。

按 [编辑与交付](references/editorial-design.md#7-主编检查) 分别验收读者理解、出版一致性和最终页面。理解检查实际重建主结论、证据、推理及关键限制，定位重复段落并记录修订；出版检查核对连续引用、数字展示与材料分工；最终文件逐页渲染检查图表、分页、链接和中文提取。改写后复核事实保真，再检查受影响的最终文件。采用用户模板和格式，用论证需要决定篇幅与图表。

关键数字从同一计算快照生成，百分比按原始精度计算；正文展示足以复算的输入，或就近说明舍入依据。使用 [出版一致性工具](references/publication-checks.md) 生成连续引用及检查数字、重复与工具痕迹提示。工具结果说明实际覆盖，读者理解由主编审读支持。重要错误完成修正、收窄或撤回受影响判断后交付。

对行业或决策报告，还检查覆盖表、情景概率及依据、期限与分区、未来回款前的融资缺口、漏斗分母和右删失、尽调问题与行动的对应。分别报告原始出处核对、计算复算、独立印证、视觉检查和外部同行评审的实际范围。

承诺研究包时交付真实输入、脚本、派生结果、相关记录和可用入口，检查包内容并在可行时重放。[研究包协议](references/research-pack.md) 保留 2.6 的兼容命令；数值工具负责算术和声明检查，作者继续完成来源、推理与覆盖判断。

用户另行要求评估或横向评分时，读取 [评估协议说明](references/report-evaluation.md)，选定一个协议后保持同批报告一致。生成过程用十维目标指导成稿，正式分数按被选中的评估协议计算。

## 持续采用的正确做法

事实、客户数量、结果、访问经历、日期、交易条件、现金、临床分母和价格均追溯到实际记录；假设明确标注并服务条件推演。把 AI 生成、AI 辅助、发现与优化写成具体职责。分别用适合的证据支持技术表现、患者获益、到账收入和盈利。保留冲突、负面发现、样本选择及成熟度限制。根据真实可比性选择企业与估值方法，使用有权使用的素材；访谈、联系第三方或持续监测以用户对该行动的授权为依据。
