# 将评估要求转成写作目标

用于拟纲、分配研究深度和交付前自查。将两套评估要求中的共同目标落实到正文、方法注和工具中。生成质量的证据是具体内容和实际核查记录；下表是工作指引。

## 十维生成目标

| 维度 | 希望写出的内容 | 验收时查看 |
|---|---|---|
| 问题定义与定位 | 读者、类型、用途、核心问题、范围和时间相互匹配 | 用户选择、确认大纲和最终标题正文的对应 |
| 框架完整性 | 覆盖回答问题的必要环节和比较；全景包含完整产业地图 | 必答问题→必要比较→正文位置→深度或缺口 |
| 事实、证据与时效 | 关键事实有准确原始定位、日期、口径与支持范围 | 真实打开的原文、事件日/期间/核查日、动态更新 |
| 信息增量 | 相较读者易得资料，增加核验、统一口径、综合认识或新证据 | 明确的合法公开替代资料和本文增加的成果 |
| 分析深度与推理 | 解释证据怎样支持判断，并比较最强替代解释 | 观察→机制→判别证据→判断→边界与更新 |
| 定量纪律 | 重要数字可复算；事实、假设、条件结果各有身份 | 统一期间/币种/分母、输入、公式、敏感性、同一快照 |
| 行业机制与落地 | 说明买方、预算、工作流、交付成本、替代方案、价值及权利流向 | 实际任务、采用阻力、议价、实施和切换成本 |
| 反证、独立性与边界 | 处理主要反例、利益关系和来源链，并据此调整判断 | 最强反证、独立观察路径、剩余混杂、受影响范围 |
| 决策可用性与工具 | 提供适配用途、带输入和规则的下一步工具 | 输入来源→判断规则→行动→验收→更新信号 |
| 论证可读性与交付 | 摘要自含、已有发现突出、术语就地解释、问题链连贯、文件可用 | 实际理解重建、重复段落处理、材料分工、数字展示与连续引用；事实保真和逐页渲染分别记录 |

## 按主用途分配深度

- **orientation 行业入门**：先解释行业地图、需求、路线、竞争与现实工作流，提供后续学习或跟踪路径；用可理解的语境承接关键定量层。
- **investment 投资尽调**：重点核查关键证据、合同与权利、现金、可比口径、最强反证和敏感性，给出投入资源前的验证要求。
- **technical 技术调研**：重点解释方法、数据、划分、基线、资源、外部有效性、复现条件和技术选择；报告已有数字仍需核对。
- **strategy 企业战略**：围绕买方预算、工作流、价值捕获、实施成本、替代品和方案权衡，给出试点、采购或进入市场条件。
- **publication 对外交付**：强化关键事实检查、准确表达、读者理解、图表、授权素材和文档可用性，同时保留分析增量。
- **balanced 综合观察**：均衡覆盖证据、推理、增量与工具，用于用户选择的中性任务。

## 完整性与定量层的范围

行业全景对照 [industry-framework.md](industry-framework.md) 和覆盖表落实各维度。专题按已确认问题配置内容，必要模块以回答是否充分验收。全景或决策展望沿用2.6的概率情景要求，采用经验、模型或有理由的作者主观权重；历史描述按任务处理。现金压力适用于融资会改变判断的公司；有来源历史临床漏斗适用于广泛AI制药研究。数据缺口用透明估计、阈值或明确待补项表达。

## 可直接使用的工具

按任务选择最有帮助的形式：估值锚、定价规则、概率情景与观察窗口、尽调清单、判断更新矩阵、跟踪指标、技术路线选择表、复现实验方案或学习地图。每项写清服务的选择、输入出处、判断规则、代价、适用范围和更新信号。用工具对决策的实际帮助确定数量。

## 参考协议与版本

2026-10-28 的1.0版对照了 `Bohrium 安装的 research-report-evaluator` 的十维细则及Codex评估技能1.0.0；本次1.1版于2026-10-29进一步对照实际可访问的Codex `research-report-evaluator` 1.1.0可读性判据，把理解重建、阅读成本和具体段落依据落实到编辑验收。生成自查按内容改进，正式评分仍使用被选中的完整协议和权重版本。

正式评分按 [report-evaluation.md](report-evaluation.md) 选择协议。两份参考的维度、量尺、权重和底线规则各有定义；同批正式比较统一使用选定版本。此处的自查记录列“完成／待补／按范围另行处理”，每项附位置、证据和影响；它服务修订与交付。
