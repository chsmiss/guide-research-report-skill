# 研究深度与竞争机制

## 1. 三个层次

1. 已核实描述：事实、观察期、来源和比较群体。
2. 机制检验：为何结果有差异；提出能产生不同预测的替代机制。
3. 增量推断：相较既有研究确认、修正或挑战了什么，以及剩余未知。

准确综述可以有整合价值。主张原创推断时，展示第二或第三层实际增加的分析。

## 2. 核心命题的机制卡

| 字段 | 内容 |
|---|---|
| 观察 | 窄且已核实的事实，因果解释另列 |
| H1 | 偏好的机制和预测 |
| H2 | 有依据的替代机制及其不同预测 |
| 判别观察 | 哪种模式或检验能区分两者 |
| 实际证据 | 各自证据及来源链独立性 |
| 剩余混杂 | 尚待支持的推断 |
| 后果 | 条件成立时读者应采取的选择 |

**合成推理示例**：软件收入和模型表现出现差异。H1认为可靠性制约采用，预测外部任务结果偏弱；H2认为部署与合规成本抵消技术收益，预测试点表现较好而部署或续约偏弱。分别取得对应证据，再决定解释强度。此例演示分析方法。

## 3. 可比基线

定义单位：预测、化合物、已验证命中、项目、临床资产、客户、业务部、公司或行业。对齐地区、年份、暴露、组合、试验阶段、适应证、基线和成熟度。“更快”使用同一时钟及结果阈值；“更高成功率”使用成熟队列、完整失败暴露与删失处理。基准结果按任务归因，客户ROI和患者结局另设比较。

## 4. 与既有研究对照

逐项判断是复现/印证、幅度修正、机制或边界更新、群体差异、遗漏变量或新失败模式。检索相关原始研究后界定增量；有独立证据的关键确认本身有价值。

## 5. 分配精力

优先研究约3–7项高杠杆不确定性，按 **潜在决策变化×不确定性×可学到的程度** 调整实际数量和深度。背景材料从简。边际新增信息反复时评估停止条件；高质量矛盾证据进入判断与修订。

## 6. 出版前挑战

寻找“能够产生相似数据，却意味着不同建议”的合理机制。若仍待区分，并列有依据的解释，给出取得关键资料前的稳健行动和后续补证要求。

## 7. 分类检验与结果

按 [decision-tests.md](decision-tests.md) 区分分部剔除、付款延期、因果比较、敏感性和情景。记录保持与改变的因素，以及已执行、假设下已计算或计划状态。思想实验用于提出问题，经验结果由实际观察支持。缺少比较时保留相应缺口，将偏差方向与处理效应列为待检假说。
