# 2.6到引导生成研报1.0的迁移核对

## 独立身份与范围

来源为创建时实际读取的 `deep-tech-research-report` 2.6.0。本技能目录和机器名为 `guided-research-report`，界面名为“引导生成研报skill”，初始独立版本1.0.0，当前版本1.1.0。原2.6目录继续保留。入口和全部13份继承研究指导文档已改为行动导向中文表达，写作计划和使用说明同步更新。

## 保留的重要能力

| 2.6能力 | 新技能位置与处理 |
|---|---|
| 行业地图、市场测算、政策、资本周期 | industry-framework与覆盖表，保留条件估计和具体缺口 |
| 联动情景与数值概率 | scenarios-and-diligence，保留经验/模型/主观依据、期限、互斥穷尽、敏感性和更新 |
| 逐期现金压力 | scenarios-and-diligence，保留延期、融资缺位、期内缺口与增量融资需求 |
| 历史临床漏斗与右删失 | biotech-ai4s及scenarios-and-diligence，保留兼容分母、LOA与AI队列区分 |
| 原始核查、来源链与反证 | evidence-audit，保留独立观察路径、状态、最强替代解释和检查范围 |
| 判断、挑战、决策检验与兼容CSV | research-pack及原脚本和模板，接口保持一致 |
| 中文论证、图表、逐页检查与提取 | editorial-design，保留版式参数、CJK映射修复条件与真实检查记录 |
| 正式报告评价 | report-evaluation，保留原八维兼容协议，并衔接独立用途化十维协议 |

## 新增与表达方法

新增类型/用途选择、范围约定和大纲确认；用户已明确选择、获批大纲或授权自主完成时使用该依据。新增十维生成质量映射，参考Bohrium及Codex两套research-report-evaluator要求。大纲提出预期信息增量与所需证据，确认后开展完整研究。

| 原否定式要求的意图 | 本技能采用的正向行动 |
|---|---|
| 防止把合同总额当收入 | 分开记录条件上限、首付、到账与确认收入 |
| 防止凭来源数声称独立性 | 追踪谁生成观察，记录独立观察路径与依据 |
| 防止用假数字填缺项 | 使用已核查输入和明示假设，缺项附影响与补证方向 |
| 防止遗漏广泛报告内容 | 用覆盖约定检查每项必要问题、正文位置与具体缺口 |
| 防止营销叙事替代分析 | 解释具体任务、基线、资源、对照和实际价值流 |
| 防止过度谨慎而只有警告 | 写清当前支持的判断、条件和下一步判别行动 |
| 防止润色改变证据含义 | 编辑后重查数字、条件、因果范围和引用 |

表达改写针对模型的研究与写作指令。脚本逻辑、错误信息、枚举、公式、负面发现、失败项目、测试输入及合成标识保持其科学和程序含义。否定词检索用于发现仍可改写的表达，成效需看实际遵循与研报质量。

## 验证边界

1.1版根据实际交付中的引用断号、展示精度尾差、附录工具痕迹及重复限定，更新编辑协议、生成质量映射和计划模板，新增标准库出版一致性工具。工具检查连续编号、显示舍入和指定数值上下文，并给出重复与技术痕迹审读提示；语义理解、来源真实性与逐页视觉检查各自执行。原继承脚本和数值接口保持兼容，旧报告保持原样。

交付时分别记录结构校验、相对链接、继承脚本/模板一致性、工具回归、数值演示重放、原版前后哈希和ZIP内容核对。确认流程另用代表请求做人工路径走查。此类检查支持结构与兼容性结论；新旧技能生成研报的质量比较，需要固定任务、证据与预算的后续评测。
