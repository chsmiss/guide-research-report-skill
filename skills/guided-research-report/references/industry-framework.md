# 通用行业研报的完整地图

用于行业全景或承诺综合覆盖的任务。专题按已确认问题配置内容。完整性以实际回答的必要问题与比较验收，章节与篇幅由论证决定。先让陌生读者理解产业地图，再进入案例。

## 覆盖约定

用 [industry_coverage.csv](../templates/industry_coverage.csv) 或等价笔记登记问题、最低比较、出处或假设、实际发现和位置、重要缺口及决策影响。`covered`附发现；`bounded_estimate`附可复算估计；`incomplete`附明确缺口；`not_applicable`附范围理由。

| 维度 | 读者需要理解 | 最低有用分析 |
|---|---|---|
| 需求与工作流 | 谁为何付钱，预算从哪来？ | 原有流程、瓶颈、支出类别、自建/购买/合作及采用摩擦 |
| 产业链 | 谁供应、执行、付费和拥有？ | 数据/模型/算力、设计实验、平台服务、开发制造和准入；展示钱、交付物及数据/IP流向 |
| 市场规模 | 定义内年度付费机会多大？ | 买方/任务×年度支出×可触达与采用比例，带日期区间、敏感性、重叠处理及可行的自上而下校核 |
| 技术与验证 | 哪个任务改善，证据到哪层？ | 基线、资源、外部/前瞻验证、临床成熟度及失败案例，就地解释指标 |
| 竞争与价值 | 产品怎样替代，谁留住价值？ | 经营/生态/估值组、客户选择、交付成本、切换、数据/IP及复用 |
| 政策与准入 | 哪些规则改变采用、数据、验证或支付？ | 适用地区、草案/约束状态、生效日、活动、机会成本与企业影响 |
| 资本与流动性 | 融资供给怎样匹配研发周期？ | 融资、药企外部创新预算、退出/合作、资本成本、消耗与融资需求的同期间比较 |
| 经济性与风险 | 收入和现金来自哪里，何时改变判断？ | 分部和会计桥接、到账、集中度、权利义务、最强替代解释 |
| 概率展望 | 哪些联动未来状态重要？ | 截止日、互斥穷尽状态、数值权重及依据、驱动、同口径结果、敏感性和更新 |
| 尽调与行动 | 投入资源前验证什么？ | 按风险排序的证据请求、验收或红旗标准、角色、行动及私有信息缺口 |

广泛报告实质解释相关地区的政策和资本周期。可合并章节，只要读者能找到相应论证；监管举例需覆盖承诺的地区，融资记录需进一步解释机制。

## 稀疏资料下的市场测算

1. 定义年份、地区、币种、产品/服务、付费方和预算。年度供应商收入、内部研发支出、条件权利价值、融资和市值分别成池。
2. 拆分实质独立的买方预算或任务池。买方模型=`潜在买方数×年度单买方支出`；SAM乘可触达比例，已服务情景再乘采用率。任务模型使用合格任务数与单价，每项保留单位和原始输入。
3. 区间来自可行观察或明示作者假设。引用可取得的买方数量、价格锚、采购和可比合同；外推、跨地区移用及校核写清。条件低/中/高结果保持假设身份。
4. 对捆绑、重叠预算、硬件加服务转售、合同内成本去重。同一支出计一次；独立预算可单列。药企需求与邻近AI4S应用分开。
5. 解释采用约束和敏感性；公司SOM需公司份额或产能依据。第三方预测先统一定义，剩余差异分开展示。

全景通常给有边界的数值模型。关键变量缺少可辩护锚点时，展示公式、阈值/盈亏平衡和敏感性，把缺项标在结果旁，市场估计记 `incomplete` 并保留补证路径。条件演示与实测市场发现分别陈述。

## 将政策解释成经济机制

取得政府/监管原始记录，注明地区、发布者、标题、发表日、生效日和状态。中国相关生物医药按活动选择NMPA/CDE证据要求、隐私/人遗/跨境、IP、扶持和支付政策；美欧按实际药物、AI/数据和准入活动选择适用框架。

逐条解释活动改变、成本或准入归属和商业模式影响。区分资金鼓励、法律许可、草案、约束义务、模型验证、药品批准、许可和报销。比较重要地区的实质差异，将政策不确定性接入情景和可观察触发器，解释强度与记录相符。

## 将资本周期解释成融资与选择机制

选定同口径历史窗口和未来期限。对齐公私企业、阶段、地区、债股、宣布/交割、IPO实收和并购价值。样本总量附覆盖框；趋势图使用一致时间序列。

追踪融资供给和回报要求怎样改变runway、项目优先级、许可条件、研发容量及退出。药企采购预算与投资者资金分开，逐项检验融资成本和竞争变化的影响。

融资敏感公司桥接可用现金和义务，给出回款延迟与新融资缺位情景，必要时增加开发延误/成本压力。拟融资保持条件身份，稀释与收入分开。先展示期内融资缺口，再解释终值，并说明可见项目的存活/选择偏差。参见 [scenarios-and-diligence.md](scenarios-and-diligence.md)。

## 编辑验收

读者应能先找到工作流、资金和权利，再解读临床p值或估值倍数；能比较市场边界、政策和融资暴露，再理解权重与尽调重点。最终范围声明列出实际完成及待补维度，覆盖依据是正文回答。
